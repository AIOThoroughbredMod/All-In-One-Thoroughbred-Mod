=== AIO Thoroughbred Mod — Editable Jockey Silk & Cap Textures ===

You can freely edit any of the PNG pattern masks in this folder using Paint.NET, Aseprite, Photoshop, or Blockbench!
- body_pattern_<id>.png   (8x12 grid: White pixels = Pattern Color, Black/Transparent = Body Base Color)
- sleeve_pattern_<id>.png (4x10 grid: White pixels = Pattern Color, Black/Transparent = Sleeve Base Color)
- cap_pattern_<id>.png    (8x8 grid:  White pixels = Pattern Color, Black/Transparent = Cap Base Color)

After saving any PNG in this folder, click [Reload PNGs] inside the Jockey Silk Creation Studio (/tb owner)
to immediately apply your custom pixel art to both the 2D GUI and the 3D Jockey Armor & Cap in-game!
