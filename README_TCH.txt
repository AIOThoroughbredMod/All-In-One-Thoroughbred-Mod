== 如何開始？ ==

當您建立新世界時，系統會提示您選擇「世界馬年時間流」- 這將決定您世界中馬年的計算方式。
預設為「一年時間流」- 專為追求完全寫實的伺服器設計。小馬的成長與母馬的發情週期，皆依照現實生活中的時間尺度進行。
對於三或四個月為一週期的設定，每三或四個月即算作一個馬年，而每個新的馬年被稱為「季節」- 此設定專為希望遊戲進度快速，但仍需在可均分為 12 個月的合理時間範圍內進行的伺服器而設計。
以上選項都沒有吸引到你嗎？你也可以設定自己的自訂時間流！

警告：一旦為您的世界選擇了時間流，便無法再切換至其他時間流，請謹慎選擇！

== 我已經選擇了時間流，接下來該怎麼做？ ==

此模組將 Lightman's Currency 模組列為其依賴項之一 - 金錢！
遺憾的是，若沒有金錢，你目前還無法成為馬主！但你仍可馴服原版中的野生馬匹，為接下來的發展做好準備。
在此模組中，銅幣的價值為 $1 元，因此讓我們先賺取至少 $10000 元。一旦賺取了價值 $10000 元的資金，即可輸入指令 /tb cash in 將錢存入銀行，接著便可著手準備成為馬主。輸入 /tb cash out 會將您的資金提取出來，並將其轉換回硬幣。
輸入 /tb owner 指令，系統會彈出註冊表單的圖形介面。填寫完畢後，你必須支付 $10000 才能完成註冊。
恭喜！你現在已經是馬主了，可以開始擁有純種馬了！

若您想事後修改註冊內容，可再次輸入 /tb owner 指令進行修改。不過，修改需支付手續費，因此請務必在初次註冊時確認所有資訊都正確無誤！

金錢不僅僅是用來成為馬主，還有更多用途，這些就留待您自行發掘了。

== 我已經註冊成為馬主了，接下來該怎麼做？ ==

既然你已經成為馬主，首先要做的是製作一份「純種馬登記表」，然後將其應用於一匹已馴服的原版馬身上。如果你沒有任何已馴服的原版馬，就出門去找一匹吧！
使用登記表後，會彈出一個登記介面 - 要求你為馬匹命名並選擇性別。
您可以從三種語言規則中選擇一種來為您的馬匹命名 - 英語、中文和日語，這三種規則分別遵循英國賽馬協會、香港賽馬會及日本中央競馬會的命名規則。
一旦您決定了馬的名字和性別，這匹馬就會成為一匹註冊的純種馬！從外表來看，牠與原版馬毫無二致，但在本質上，牠已經經歷了徹底的蛻變，不再遵循原版馬的 AI 行為模式 - 這一點在騎乘時便能明顯感受到（記得先為牠套上馬鞍！）。

完成馬匹註冊後，系統會彈出一個純種馬資料卡的介面，顯示該馬匹的完整資訊。若想再次查看，你可以先蹲下再右鍵點擊馬匹。

== 我已將馬登記為純種馬，接下來該怎麼做？ ==

現在，你可以自行探索其他所有內容了！從馬匹訓練、賽馬、照料到繁殖，有許多可能性。
試試看純種馬的操作方式 - 牠已不再遵循原版馬匹的操作設定。
按下 G 鍵可啟用「訓練模式」，在此模式下，你可以開始訓練五項核心屬性：速度、耐力、力量、意志力與智慧。
速度 - 馬匹奔跑的速度。
耐力 - 馬匹的「燃料」，決定馬匹能奔跑多久。
力量 - 影響馬匹的加速能力及攀爬上坡的能力。牠還能讓馬匹邁出強勁的步幅，藉此獲得短暫的速度提升。
意志力 - 一旦耐力耗盡，馬匹將動用其意志力儲備，這會停止進一步加速，並決定牠能維持當前速度的時間長短。根據你的意志力值高低，這也決定了當耐力與意志力皆耗盡時，速度下降的速率。
智慧 - 影響馬匹的呼吸節奏及其對馬鞭的反應 - 這項道具能促使馬匹發揮自身所有實力。智慧低的馬匹可能會出現呼吸不穩的狀況，並造成不必要的體力消耗，且需要更多次使用馬鞭的催促，才能達到其最高速度。

== 騎馬時這些進度條代表什麼？ ==

SPD - 顯示馬匹當前奔跑速度的進度條。紅色進度條代表馬匹的舒適奔跑區間，在使用馬鞭之前，此區間將作為軟性上限。灰色進度條則是馬匹的速度硬性上限，即馬匹能夠達到的最高奔跑速度。
STM - 馬匹的耐力儲備，當馬匹速度超過每小時 35 公里時，耐力便會開始消耗。當馬匹呼吸不穩時，其狀態指示會於紅色與藍色之間閃爍，並導致不必要的耐力消耗。當其完全耗盡後，GUTS 進度條將接替其作用，並持續供應至無法再供應為止。
GUTS — 馬匹的意志力儲備，當耐力降至零時會出現。會阻止進一步加速，但能維持當前速度穩定，直到意志力儲備最終耗盡為止。
距離適性數值（X 公尺／XXXX 公尺-XXXX 公尺）- 馬匹的最低與最高距離適性。當你的馬匹超過其最大距離適性上限時，耐力條會在50公尺的距離內緩慢閃爍並加速消耗，隨後轉為快速閃爍，導致耐力極速耗盡。最低距離適性會影響馬匹何時能開始被馬鞭催促 - 此時會存在一個「隱形」的最低閾值（即最低適性值減去 500），因此馬匹即使在適性值僅勉強達標的賽事中，也能以最大努力奔跑。
HNG 與 THR - 馬匹的飢餓與口渴度。如果馬匹處於飢餓或脫水狀態，訓練將毫無成效！請餵食馬糧並提供飲水！馬匹也會自動食用放置在地面上的乾草捆，並飲用鍋釜中的水。餵食馬匹一顆附魔金蘋果，可使飢餓與口渴的狀態暫停現實時間兩天。
FTG - 馬匹的疲勞度，你務必密切留意這項數值 - 當馬匹疲勞度達到 50% 時，牠便變得容易生病，並開始面臨受傷的風險。一旦超過 80%，便會進入危險區，導致馬匹罹患「腿部不穩」的病症 - 這會使受傷機率飆升，甚至可能造成災難性的後果！您可以使用梳理刷為馬匹梳理毛髮，或讓牠休息，以減輕疲勞。餵食馬匹一顆附魔金蘋果，可減輕疲勞，並在接下來的兩天內大幅抑制（但無法完全阻止）疲勞的累積。
BND - 馬匹的羈絆值。好好照顧你的馬匹能提升牠的羈絆值與心情，從而為你的訓練帶來加成！
MOOD - 馬匹的心情。這會影響馬匹的訓練成效以及賽事表現，所以要讓牠保持愉快的心情！

== 我的馬生病／受傷了，現在該怎麼辦？ ==

天啊！看來你讓牠長時間處於疲勞狀態，結果牠出事了！
當這種情況發生時，你可以輸入 /tb vet 指令 - 只要資金充足，系統便會立即向你收取費用，為你的馬匹進行治療。關於傷勢，獸醫雖無法直接治癒，但能將恢復速度提升一半，並提高完全康復的機率。傷勢有機會導致馬匹的競賽能力下降或永久喪失，而獸醫能降低這種情況發生的機率。

如果你的馬遭受了災難性骨折，也就是說預後不良已是定論，那麼沒有任何方法能救牠，就連獸醫也無能為力。牠將在極度痛苦中苟延殘喘，度過這段借來的時光。每天牠都有五成機率會因這難以忍受的劇痛而死去，帶著滿腔怨恨離開這個世界 - 這從那令人毛骨悚然的凋靈聲中便可聼見... 讓這份罪惡感沉重地壓在心頭吧。使用 /tb euthanize 指令為牠實施安樂死，將讓牠有尊嚴地離去。

然而，希望尚未完全破滅！仍有 1% 的機率會發生奇蹟！餵食附魔金蘋果，能減輕牠的痛苦，並讓牠在接下來的一天內免於步入死亡之門。若持續餵食附魔金蘋果，總有一天奇蹟會發生，牠將康復 - 儘管牠極有可能完全喪失競賽能力，因為這種災難性骨折極可能摧毀牠的雙腿。能從災難性骨折中倖存下來已是奇蹟，若還期望牠能恢復競賽能力，那無異於奇蹟之上的奇蹟。

普通的黃金蘋果也能發揮同樣的效果，但有個關鍵 - 它的效果會隨使用數量增加而遞減。這意味著你使用的黃金蘋果越多，它能從隔天的死亡骰中減去的死亡機率就越少。如果你的馬還是不幸因此而死，請不要自責，牠的死得比預期更安詳，也不會懷著怨恨離開這個世界。
